# KAMEN（仮面）Custom Edition 2.0.0 検証記録

基準はSites保存済みv39（アプリ1.3.0、commit 695c4d2ba4b0282a52dcfbea0b7b1b89e5984586）。新しい保存版として公開し、v35とv39を含む既存履歴を保持する。

## 改修内容

- アプリ名・ロゴ文字・ページ情報・ヘルプをKAMEN（仮面）へ変更。ライセンスの原作者JIZURA表記と互換用識別子は維持。
- LLM用の指示コピー、JSON案の読み込み・検証・比較・適用画面を撤去。素材・解析ZIPのダウンロードを維持。外部LLMへ通信する処理は追加していない。
- 進捗を1枚のカード・1本のバーへ統合。重複する旧書き出しバーを撤去。実工程、実フレーム数、経過時間を表示し、詳細は折りたたむ。
- 成功は100%を1.2秒表示後に自動で閉じる。通常の自動保存は表示せず、1秒以上の場合だけ表示。実保存エラーは保持、引き継ぎ済み自動保存は即時終了。
- 不確定の工程に偽の%やETAを出さない。UI更新は150ms、経過時間は1秒単位。
- タップ同期を音声再生時計へ接続。Spaceのキーリピートを抑止、1行取り消し、逆順防止、終了時の保存とUndo履歴、素材変更の検知を追加。
- UTF-8 LRC出力を追加。ミリ秒精度、時刻の桁上がり、offsetの二重適用防止、整合する単語タイムスタンプの維持、未同期・逆順・音源外の時刻を検証。未同期行を推定時刻で埋めない。
- フォントの実描画ウェイトを安全領域の測定に反映する不具合を修正。
- 明確な短い日本語命令形に限定したローカル文字演出を追加。貫け→pierce、昇れ→rise、集まれ→unite。元の構図・カメラ・文字グループを維持し、手動指定・保存済みDirector・大きな見せ場・否定・引用・曖昧な表現を優先する。正方形pierceは実測で移動が制限されたため従来演出を維持。
- ZIP作成中の二重実行と素材差し替えを防止。

## 実測性能と精度

解析入力は固定したデコード済みPCM。音声読み込み・ブラウザdecodeAudioDataは測定対象外。3回中央値。BPM、ビート、波形、全特徴量・配列がv39と厳密一致。追加で22.05/44.1/96kHz・3チャンネルも一致。

| 入力 | Before | After | 短縮率 |
|---|---:|---:|---:|
| provided-audio | 960.25 ms | 878.73 ms | 8.49% |
| stereo-rhythmic-120s | 1631.90 ms | 1486.17 ms | 8.93% |
| silence | 42.70 ms | 47.93 ms | -12.24% |

2秒の無音は約5.23ms遅くなった。FFT係数の準備コストによるもので、短い全入力の高速化は主張しない。解析中の追加一時領域は約22KB＋50Hz特徴サンプルあたり8bytes。常駐キャッシュや保存データへの追加はない。

時系列探索は10分相当・6000特徴フレームの合成データ、5回中央値。計算結果と順序を保持する索引化。MV全体の生成時間ではない。

| 処理 | Before | After | 短縮率 |
|---|---:|---:|---:|
| musicalStructure | 641.88 ms | 51.83 ms | 91.93% |
| beatHierarchy | 1817.42 ms | 35.27 ms | 98.06% |

初期起動、ブラウザ音源デコード、プロジェクト再読込、プレビュー開始、ブラウザ動画書き出しのBefore/Afterは未測定。GPU描画・エンコードの速度改善は主張しない。解像度、FPS、ビットレート、音声設定、FFTサイズ、特徴量の間隔は低下させていない。依存パッケージは変更していない。

## 品質確認

- 非対象歌詞の20フレームは4アスペクトでv39と画素一致。
- 添付素材から再構成した25行を、各3時点×4アスペクト＝300フレームで検査。歌詞画素と安全領域を確認。
- 元音源を実デコードした最終フレームQAはerrors=[]、ready=true。適用した4行のpierce動作は実画素検査で各100。20件の演出は可視率100%、主要演出の100ms以内一致100%、欠落0。
- motionRealization参考値は75→73。これは一部演出の画素変化強度比の低下で、欠落・同期失敗ではない。反復演出の注意は残る。全品質指標の上昇や芸術品質100点を保証する結果ではない。
- 実Canvas→FFmpegで横1920×1080、縦1080×1920、正方形1080×1080の2秒MP4を作成。各60フレーム、30fps、H.264/AAC、48kHz/192kbps。MP4解析、フレームと音声の実デコードが成功。
- このMP4検査はブラウザWebCodecsの実端末検査ではない。元の完全なプロジェクトJSONは添付されていないため、再構成検査は元動画の編集状態の完全再現ではない。実歌唱との聴覚同期や主観的な最良編集は未確定。

## データ・公開の保全

localStorageのjizura.project.v1/jizura.mode、IndexedDB jizura-assets-v1（version1）、project schema3を維持。旧Directorと旧素材を含む保存形式を読み込める。データの削除・初期化・移行は行わない。プロジェクト拡張子は新規出力.kamen.json、旧.jsonは継続して開ける。Site URL、所有者、共有設定、Secrets、環境変数を維持。Site表示名だけKAMEN（仮面）へ変更する。

ブラウザ実機QAは実行環境不足で未実施（可変フォント・WebCodecs E2Eの2件）。静的構文、Canvas、実音声の解析一致、隔離したUIハンドラー、保存復元、ネイティブMP4検査で評価する。
