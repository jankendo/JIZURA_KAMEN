# Song-native v10 creative optimizer

New UI generations opt into `optimizerVersion: 10`. The persisted direction and
resolved-plan renderer contract stay at version 9. Existing v3–v9 projects are
not migrated or reranked on load. v9 integrity, input/lock binding, atomic search
commit, final composed-frame gates, repair finalization and rollback still apply.

The previous local role search compared only target amplitude (with further
scaling for background/decor/transition/FX). v10 separates amplitude priors from
measured composition/continuity, observed change and same-time ablation gains.
Component amplitudes reuse v8 metadata locally; unidentified amplitudes remain
explicit tag priors. No component name earns a quality bonus. RGB cell distance
proves realization and never earns an artistic-quality score.

Each line starts with audio/image/lyric style profiles and existing full-phrase
Canvas geometry candidates. A bounded shortlist includes independent roles,
hold/camera, background/treatment and other component pairs, spatial alternatives
from image analysis, and input-ranked full combinations. Pairs reach Canvas
before individual roles are committed. All candidates use existing registry
methods. Midpoint eligibility and Pareto/local-fit ranking bound full-phase work.
The best phase-safe states undergo single-component ablations at **identical
sample times**; invisible safe-to-remove components are removed and reranked.
The baseline remains an eligible competitor. Call-local raster memoization is
cleared between lyric lines; completed sequences receive fresh safety probes.
Low-amplitude calibrated supporting components survive into cross-pair probes.
No intermediate encoding, random assignment or genre/storyboard profiles exist.

The existing global beam accepts an acoustic-only pacing option for v10. It
compares local acoustic differences with rendered glyph geometry/temporal change,
penalizes unsupported style changes and relates repeated lyrics. The legacy beam
heuristics remain unchanged for old versions. The collapse audit requests a
second search only with measured acoustic change, inadequate visual response,
and an available safe candidate with better fit/comparable composition. An
unresolved audit blocks commit; no technique-count quota is used. Ineligible
optional alternate storyboards are omitted. Switching alternatives switches their
own diagnostics and retains the independently verified prior storyboard.

The existing detail UI shows selected cut-owned roles, FX/transition, acoustic
reason, comparison count and ablation evidence. Observed camera transforms are
captured from actual Renderer registry calls. Quality observations retain null
scores where no artistic measurement exists. Main-MV evidence never certifies a
12–15 second Short; human artistic quality remains UNVERIFIED.

## Bounded validation

`node dev/kamen_song_native_v10_fast_test.cjs` contains four synthetic tests:

1. Realized contribution, quiet stillness versus an active line, actual registry
   dispatch and selected-cut UI values.
2. Existing breathe/push joint rendering versus either component, bg/treatment
   interaction observations, acoustic-order causality, repeatable decisions,
   collapse-audit conditions, safety exclusions and manual locks.
3. Complete Japanese glyphs, contrast and safe bounds in both aspects, honest
   measured/unmeasured states; no encoding.
4. Exact v10 persistence, v3–v9 legacy restoration, independently validated
   alternatives, input identity, repair finalization and fast/quality settings.

The existing FAST checks remain enabled, with v10 added. The browser smoke uses
the real creation button, checks v10 selection/arc state, production observation,
round-trip persistence, alternate application and failure rollback.

These are bounded engineering checks, not a subjective-art or virality verdict.
Long real songs, all-frame MP4 artistic quality, dedicated Shorts, subjective
human review and acceleration ratios remain unverified. No hard-gate thresholds
were lowered and no full test suite or MP4 benchmark is part of this change.
