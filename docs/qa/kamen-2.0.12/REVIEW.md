## 変更

- 背景のWIDE/MEDIUM/DETAILを実際の異なるクロップに対応させた。導入は音源の既存ビートに同期した同じ画像の色調・構図・タイトル表示、歌詞部分は全文を保持する短い収束、反復は寄りの変化、アウトロは冒頭の広角へ戻る。音源と歌詞時刻は変更しない。
- 実際の選択スタイルの装飾を描画。前景装飾は歌詞矩形から除外し、背面装飾は文字より前に描く。スタイル比較時にも同じ装飾を使用。カタログの未比較スタイルを名前だけで成功扱いしない。
- アクセントの除去比較ではcut.styleにも比較用パレットを適用する。従来は元の色が残っていた。採点の45/35/20の配点と画素閾値は変更していない。
- 元画像の欠落していた記述子を実画素から取得。指定された単一画像の再使用に、画像候補順位の再使用罰則を重ねない。CHANTの既存分類によるunity役割を明記し、画像の人物認識や意味理解とは区別する。
- ループの固定65を廃止し、既存の音楽・カメラ連続性計算を曲全体にも実行。終了境界で旧カメラに飛ぶバグを修正した。85という結果もそのまま残す。
- 独立画素観測で最初と最後の有効な画素差分を捨てない。最初の音源ビート0.06秒の強い変化が検出されなかった問題を修正。閾値・画素チャネル・重み・100ms許容は維持。
- 明示した演出は元の音源ビートに存在する時刻に限り、拍の期待対象へ渡す。無関係な演出時刻を音楽対象へ追加することはテストで禁止した。
- 曲全体で歌詞の字形の高さを既存の選択検査の範囲に実際に収める。文字を消したり、検査閾値を上げたりしない。
- 全測定領域90点、正規化した詳細80点、既存エラーなしを個別判定。秒数・ショット数は100点尺度に混ぜない。未測定を100点にはしない。
- 完成MP4を最大5回まで採点・修正して再生成。最も弱い項目・失敗数を優先して最良の実ファイルと対応する計画・ハッシュを保持する。同じ描画に収束した時点で停止し、未達・停止理由をsidecarに残す。無限再生成・点数の上書きは行わない。従来の100認定も新しい個別条件を満たさなければ取り消す。
- Asset Packへ音楽の詳細タイムライン・エネルギー・解析率を保存し、再検証時に音楽の展開を定数として復元しない。

## 検証と限界

元PNG、LRC、AACを使用。音楽特徴を元PCMから再計算し、保存されたブラウザ選択を復元。1280×720・30fps・50.8秒・1524フレームを実際に描画・H.264/AACへエンコード。ffprobeの構造検査と、デコード後の独立画素観測を実行した。音源のデコードPCM SHA-256は書き出し前後で一致。

`attempt-1/2/3-decoded-score.json` と `final-decoded-score.json` に実試行結果を記録。最後は4つの詳細未達を保持し、targetAcceptance.minimumMet=false / certified100=false。動画の任意区間の短縮・音源変更・架空のクライマックス・意味点・観客評価は追加していない。

カタログ検査は24スタイル、724手法、24書体候補、4476回のレンダラー呼び出し。選択検査は1094比較フレームと16:9/9:16/1:1/4:5の120歌詞検査を通過。エンジン回帰は162成功・2件環境不足によるスキップ。変更後の個別最低点、5回再生成、ハッシュ復元、手動指定保持も検査した。

ネイティブCanvas・ffmpegの検証であり、新版のWindows Chrome / WebCodecs書き出しを確認した結果ではない。24書体の実ブラウザでのロード結果も代替しない。実行時は利用できないフォントを候補から除外し、内蔵フォントへ退避する。字形の存在・安全領域・画素差分は、芸術的完成度・歌唱の知覚同期・SNSの視聴者反応を認定しない。
