# Song-Native v9 selection integrity

New generation uses schema/renderer 9. Existing v3–v8 directions keep their dispatch and saved payloads. No legacy selection is silently migrated.

The confirmed contract checks source identity, renderer compatibility, manual locks, automatic-line coverage, registered IDs, exact cut/entry agreement, and phase-safe production Canvas evidence. DRAFT and STALE plans cannot be committed as completed storyboards. Search works on a clone and commits the complete winner after input checks. Generation suppresses intermediate autosave and restores the previous project/plan on failure.

The previous v8 path accepted `selection: null`, installed center/cut/still baseline cuts carrying `registrySelectedV8`, and accepted a valid Direction without checking selection completeness. Repair could restore Direction metadata independently of repaired cuts. The alternative button regenerated an unsearched proposal. These paths explain how an unselected baseline could survive finalization; no supplied failing project was available to establish which path produced the reported screenshot. Baseline candidates did not populate `styleKey`, explaining the undefined style label. Overall scoring averaged only available domains and the UI replaced missing creative/social scores with overall.

v9 ranks live registry components, probes bounded shortlists, compares current settings before adding effects, reuses rendered storyboard beam search, and retains independently phase-tested alternatives. Layout safety no longer requires the center. Existing image-anchor candidates are compared by rendered contrast and image saliency. Transition durations and cut-owned FX use the same production renderer in probes and playback. Swallowed registry draw warnings reject candidates.

Four groups in `dev/kamen_song_native_v9_fast_test.cjs` cover real selection, acoustic ordering/locks, Canvas geometry and honest quality states, and fix/replan/alternative/save/restore (including v3–v8). The browser smoke drives the real generation button and asserts final selection integrity before accepting success.

Canvas differences for composition, background, repeated lyrics, opening/ending, and within-line stillness are observations with units and evidence, not artistic scores. Camera attribution, artistic quality, audience response, and main/Short SNS scores remain unmeasured when their required evidence is absent. Overall remains unconfirmed without all three scores. Short is not inferred from main-MV evidence.

Validation scope: changed JS syntax, the four-group v9 fast test, existing required FAST contracts, production build, and short Chromium UI smoke. No full validation, long-source run, MP4 full-frame review, performance/GPU/memory benchmark, or human artistic evaluation.
