# KAMEN 2.4.0 UX監査・改善記録

2026-10-26。対象はブラウザー版KAMEN。初回の素材選択から生成、確認・編集、保存・復元、動画出力までを、操作の分かりやすさ・失敗からの復帰・データ保全・MVの可読性で評価しました。現行のダークデザインは維持しています。

## 指摘と修正

| 優先度 | 再現・課題と利用者への影響 | 修正・確認 |
| --- | --- | --- |
| 高 | 現行生成に不要な旧エンジン・最適化・品質判定群とAE／CEPが同居。ビルド・CI・資料が旧仕様を引きずる。 | 現行JIZURAと背景・保存・出力アダプターへ集約。旧製品・専用テスト・生成証跡を削除。ソース一覧とCIを再構成。 |
| 高 | 旧作品を従来エンジンで開く仕様では、旧エンジンを削除できず、単純な置換では元作品を変更するおそれがある。 | 素材のみを別の作業へ変換。元レコード・素材・入力JSONを保持。再生成まで全UIのMP4経路を無効化。localStorage・DB format 2/3の移行を確認。 |
| 高 | 音源・画像・歌詞を変更しても生成状態が残り、変更後の素材で未確認の出力に進める。 | ファイル差し替えと歌詞の直接編集で生成状態を無効化。メタデータ・手動の配色／時刻調整は即時反映を維持。 |
| 中 | コマ落ち表現の時計がLRC開始時刻より前へ丸められ、歌詞の初出が遅れる。 | アクティブな歌詞カットを開始時刻より前へ戻さない境界処理を追加。12コマ表現と非整列の開始時刻で確認。上流ファイルは変更せず、ビルド時の挿入箇所を検査。 |
| 中 | 白い写真に白文字、黒い写真に黒文字では主歌詞が背景に埋もれる。 | 主歌詞の塗りに対して反対色の縁取りと影を追加。構図・時刻・演出選択は保持。長文・記号の全カット、横長／縦長／正方形の白黒背景を画素と文字範囲で確認。 |
| 中 | 曲名自動配置の文字範囲測定が、実描画の中央揃え・ベースラインと一致していない。 | 測定時の揃え・ベースラインを描画と統一。ネイティブ文字遷移、配置キャッシュ、長いUnicode曲名、明暗背景を再検証。 |
| 中 | 小さいエラー詳細ボタンなどが操作しにくく、入力時に不要な診断が露出する。 | ボタン・セレクト・ファイル選択・開閉見出しを44px以上へ。診断はエラーがあるときだけ出力欄に表示。フォーカス表示・モーション低減に対応。 |
| 中 | 出力後に曲名等を編集しても、共有対象が以前の動画のまま残る。 | 再計画で古い共有ファイルを無効化。生成済み状態は保ち、再出力後に共有する導線へ。 |
| 中 | 旧素材のフォント欠落や、旧作品の再生成の必要性が分かりにくい。 | 取り込んだ素材・欠落フォント・再生成の案内を独立表示。元の音源・フォントの再選択を案内。正常ロード後だけフォントバイナリーを登録。 |
| 低 | 書き出し設定に英語の専門用語が混在し、廃止した適応FPS経路の選択肢も残る。 | 用途別設定・ビットレート等に表記統一。24／30／60fpsを明示選択。 |

## 実装・削除範囲

アプリ側のソースは114から15モジュールへ整理しました。生成HTMLは8,668,461 bytesから5,412,427 bytesへ37.6%削減しています。JS・CSS・書体・AACを含むHTMLのサイズであり、圧縮後の転送量や体感速度の数値ではありません。

削除対象は旧KAMENの生成・探索・最適化・スコアゲート、AE／CEPソースとビルド、英語版生成補助、専用のテスト・開発依存、不要になった旧muxer、旧世代の生成QAカタログです。現行のテーマ・演出セット、歌詞同期、配色・書体、曲名表示、SNS範囲選択、MP4・PNG、ローカル保存・競合保護は維持しました。必要なライセンス・上流出典・現行検証素材は保持しています。過去資料は[履歴案内](HISTORY.md)から参照できます。

保存DBの破壊的更新はありません。旧素材取込には任意のsourceImportメタデータを使い、現行形式のseed・ロック・overrides・creditsを維持します。詳細は[保存仕様](STORAGE.md)を参照してください。

## 検証と証跡

`npm ci`、メディアビルド、本番ビルド、`npm test`、`KAMEN_LONG_EXPORT=1 npm run test:e2e` をLinux／Node.js 24／Chromiumで実行しました。単体契約は5群、ブラウザーのチェック群と可読性ケースは下記JSONに記録しています。いずれも成功し、ブラウザーpageerrorはありません。テスト対象外を成功扱いにはしていません。

- [全体・ビルド識別情報](qa/audit-2.4.0/summary.json)
- [UX・レスポンシブ・旧作品取込](qa/audit-2.4.0/ux.json)：375／768／1024／1100／1440px、通常・詳細・処理中・エラー、操作対象、フォーカス、中止・再試行、再生成待ち制御。
- [歌詞の可読性](qa/audit-2.4.0/readability.json)：長い日本語・記号の各カット、全3比率×白黒背景、文字範囲、縁取りの画素差分。
- [保存・復元・競合](qa/audit-2.4.0/workspaces.json)：別タブ分岐と画像・音源・フォントの独立性、容量不足・再保存、変更中の入力保全、旧DB移行、保存領域が使えない場合。
- [曲名・レイアウト・画像出力](qa/audit-2.4.0/credits.json)：表示区間、長文、Undo／Redo・再起動、部分MP4、H.264再試行・AAC代替、通常／透過PNG ZIP。
- [生成・実MP4](qa/audit-2.4.0/upstream.json)：上流チェックサム、seed／テーマ／時刻／ロック、720p・1080p・縦型・部分範囲、180秒の音声付き出力、中止・再試行、破損出力の拒否。

実動画はFFprobeでトラック・解像度・fps・尺を確認し、FFmpegで全体をデコードしました。PNG ZIPの画像もデコード・サイズ・アルファ・曲名画素を確認しています。スクリーンショットと実動画は `/tmp/kamen-2.4-release` にあり、個人素材を含みません。公開用のスクリーンショットや動画はリポジトリに追加していません。再実行方法は[検証手順](VALIDATION.md)を参照してください。

## 検証の限界・公開状態

自動配置はサンプル時刻の文字範囲による推定で、全画面に広がる歌詞・極端な動き・写真の被写体との重なりを完全には保証しません。縁取りは可読性を補助しますが、全技法・全seed・全素材の美的品質を認定するものではありません。実機のEdge、Windows／macOSの保存ダイアログ、物理モバイル端末は未検証です。ヘッドレス検証は通常ダウンロード経路を使っています。

この監査のローカル検証は公開前に実施しました。CIは現行検証を通過したmainへのpushでのみPagesへ公開します。切り戻しは正常コミットへのrevert PRで行います。
