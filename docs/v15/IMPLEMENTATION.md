# KAMEN v15 — Extreme Random-First Creative Finisher

## 変更と根拠

調査した最新main: `9d2e56d2caa719ade758b0fc8a19381d17af0f36`。開発版 2.0.29。

通常の `J.omakase()` は mood を抽選してスタイル、有効技法、色、フォント、強度を変更する。自動演出中のUIボタンは seed の再抽選であり、通常のおまかせを呼ばない。v13/v14 は行別のレジストリ候補探索であり、どちらとも異なる。

v14では中立値を多く含む activation 分布、motion/camera/fx の .35–1 倍、アーカイブと音楽適合による再選択が重なっていた。固定seedの実測でもカメラの時間変化は両行0だった。これらは単調さにつながる経路であり、人間の芸術評価の原因を完全に説明するものではない。

新規生成だけを v15 に切り替えた。旧版の保存データや v14 の選択器は残る。レジストリの callable / requiresAsset / randomOk / layout.fits 契約を満たす技法から、独立したseed付きストリームで抽選する。完成プロファイル、moodの技法プール、歌詞キーワード、ジャンル別の対応表は使用しない。

## Creative Genome と調整

styleKey / layout / enter / hold / exit / cam / bg / treat / decor / fx / trans を生成時と完成時に保存する。通常の数値修復でIDが変わればエラーになる。最初の安全なランダム案を確定し、v14のPareto選択器も旧全曲ビームも呼ばない。

既定の「かなり激しい」は非中立技法の抽選確率へ反映する。HOLD/CAMERA .92、BACKGROUND .85、DECOR .7、FX .6、TRANSITION .65、その他 .8。通常強度の比較設定は .4。技法数や技法IDによる品質加点はない。ほとんどの技法は元の強度1を保持し、安全修復時だけ弱める。実装を確認した drift は移動幅5%W未満・拡大7%未満となる1.4まで、pushはズーム3.9%未満となる1.3までを抽選可能とし、毎回Canvasで検証する。一律の高倍率は使わない。

歌詞長・画面比率から初期サイズと時間を合わせ、色、局所scrimと影、実際の文字境界から位置・サイズを修正する。細い文字でコントラストを計測できない場合は、縮小を続けず拡大も試す。カラー変更は複数の描画経路が共有する可読性フックへ適用する。

音楽は抽選後の登場時間だけに利用する。音楽適合スコアのために技法を変えない。元のHOLD進行を保持し、フラッシュイベントを追加しない。

## 安全修復と保持の限界

行あたり108状態以内。色・位置・サイズ・時間・強度の修復後、役割を外す対照描画で失敗の原因を調べる。原因役割のランダム代替を優先する。2つの代替でも失敗し、役割除去が観測された安全性の失敗を減らす場合に限り、その役割の中立値を使用できる。レイアウト固有の表示欠落はレイアウトだけを再抽選し、他の役割は保持する。変更理由と前後IDを保存する。

既存の256px一次検証、640px最終ゲート、全文・core coverage・安全領域・変形・コントラスト閾値を維持する。640px失敗は640px観測に基づいて数値修復する。安全な完成案が得られない場合は失敗を返し、UIが前の完成MVを復元する。

強い明滅を示すID・タグを新規抽選から除き、最終候補の先頭最大2秒を30fpsで観測する。1秒内に平均輝度差 .2 超の変化が6回以上ある場合は棄却する。全曲・全技法の光感受性安全性の証明ではない。

「今の演出を活かして仕上げる」は現在の切り出しを起点にし、役割変更を禁止する。共有FX強度とフォント設定も現在の値を引き継ぐ。実UIスモークでこの保持を確認する。手動ロックは既存境界で保護する。品質修復の再検索も現在の確定カットを起点にする。保持したまま安全にできなければ失敗として元のMVを残す。

## 検証（3グループ）

1. 実CanvasでGenome保持、位置・サイズ調整、音楽時間調整、原因役割の再抽選、ロック、seed再現、強度分布の差。
2. seed 12812、同じ4秒の合成音響情報・日本語LRC・背景による v14 / 通常のおまかせ / v15 比較。通常のおまかせは旧描画方式で1行が複数カットになるため、安全性の数値をv15の確定契約と同一視しない。
3. 640px、縦画面、保存復元、LRC、旧互換性、短いfast/quality MP4、実UIスモーク、build、required FAST CI。

比較の機械的観測は [comparison.json](comparison.json)。初回の完成試験では primary temporal change の行平均が v14 .01931、v15 .07071、v15の2行目はcamera transformの時間変化が非ゼロだった。背景・FX・カメラは同時刻の役割除去対照で可視的寄与を確認した。primary motionはカメラやレイアウトの影響を含む。背景指標は文字より前の装飾も含む。

初回完成試験のGenome保持率は行別81.8% / 63.6%。ID交換は安全修復に限定され、通常の微調整では100%保持した。退場の変形やレイアウト固有の欠落が部分交換を必要とした。修復の母集団が異なるため、v14の3/115に対する改善率は主張しない。

1秒・640×360・24fpsのfast/quality MP4はデコード再読込と基本検査を通った。背景の寄与はMP4デコードでもcodec残差を超えて観測された。カメラ・FXそれぞれの独立したMP4寄与検証は未実施。合成音響情報には音声PCMがないため、この比較MP4は無音。
