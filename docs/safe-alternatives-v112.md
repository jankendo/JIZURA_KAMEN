## Recommendation and optional variants

`11zzzzzzzzzq_safe_alternatives_v112.js` retains renderer 9 / optimizer 11 and delegates older projects to their existing implementations. Recommendation confirmation remains mandatory. Alternative exhaustion has a typed code and scope; only that exact expected outcome is converted to an empty alternative list. Cancellation, input changes, renderer errors and malformed state propagate. No safety threshold changes.

Variants keep the confirmed recommendation on unchanged lines. Input-ranked measured glyph/RGB/temporal differences, acoustic change and local fit select up to six single-line proposals. Up to two related two-line proposals may follow when acoustic demand warrants them. The existing beam/arc evaluates each complete composition. Every accepted variant passes the production 640px gate and composed temporal probes, avoids material musical-fit or unresolved-arc regression, and has an observable difference measured against its recommendation at matched times. Difference magnitude is evidence of variation, not artistic quality. The UI disables the alternative button when no safe variant exists.

The 640px gate records line/time/phase, role IDs, observed contrast/full text/geometry/size/safe area, existing criteria, rejected states and recovery outcomes. Missing measurements remain null or unmeasured. It stores numerical evidence, not raster images. Unexpected renderer failures throw explicitly. Call-local detail evidence is bounded to 192 entries and keyed by the complete installed composition. Changed rows and their neighbors are checked first; a failed alternative stops immediately. Accepted variants still receive complete composition checks.

If recommendation candidates run out, only the failed row expands once, with at most 12 distinct hypotheses and up to four low-raster-safe additions. Existing frontier representatives precede diagnosis-conditioned FX/camera removal and live layout/style capabilities. Contrast failures can revisit the same layout in a different input-ranked style. All additions use the original low-raster gates/scoring and the complete arc/640px confirmation. Exhaustion fails with diagnostics; no unsafe fallback or global restart exists.

## Creative refinement and its limits

The style frontier can expand by one to three unvisited live styles when musical fit, safe choice or geometric spread is insufficient for input demand. Existing profiles select complementary hypotheses. An adequate stable frontier adds no work; the prior no-safe fallback remains available. Added styles follow the existing Canvas, Pareto and safety path. The reused v11 test compares a weak converged frontier against the old shortlist-only stopping condition and checks that stable adequate input does not expand. This demonstrates additional search coverage, not superior human-rated art.

Existing role ablations now record same-time composited marginal contributions over entry/hold/exit and interval acoustic events. Varying measured audio/visual activity can contribute a bounded fit adjustment. Pixel-invisible roles are removed and their already-computed control score is adopted. Background, decoration and FX evidence is separately attributed to actual one-role ablations; interactions remain included. These are marginal composite observations, not isolated layer RGBA. Missing/unsafe evidence cannot claim independent layer measurements. Arc costs reuse observed layers, acoustic recurrence and measured section boundaries; no technique-count reward or forced per-line variety is added.

IndexedDB transactions, revisions, audio/asset records, resolved decisions, strict restoration, locks, legacy dispatch, backup and export implementations are retained. New optional diagnostics are ordinary JSON and pass through the existing v11.1 projection. No schema migration is required.

## Focused verification

The bounded new regression covers safe recommendation/unsafe fourth-line alternative, one-row safe variation, row-local recommendation recovery, unsafe recommendation exhaustion, renderer exceptions, input mutation and cancellation. Both no-alternative and safe-alternative selections are captured and restored through the existing compact projection. The original main is checked with the same small Canvas regression to establish the before failure.

Existing v11 Canvas scenarios and v11.1 Chromium persistence scenarios are reused, together with syntax, production build, short startup smoke and required FAST CI. No FULL suite, bulk MP4 generation, long encoding or benchmark is part of this release. Human aesthetic quality, general browser quota guarantees, encoded-video quality and wall-clock performance gains remain unverified.
