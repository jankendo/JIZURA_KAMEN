# KAMEN 2.5.0 — 聞きながら指定する書き出し範囲

音源を読み込んだ直後から、連続した1区間を秒数で指定できます。MV全体の生成・歌詞時刻を維持し、指定区間だけをMP4へ切り出します。複数区間の連結やフェード処理は追加しません。

## 操作とレイアウト

再生操作の直下に「書き出す範囲」を配置しました。従来の詳細設定内の範囲選択をここへ移し、「曲全体」「秒数で指定」「縦型ショート」「SNS 60秒版」をまとめています。音源だけの状態では空の映像領域を隠し、再生と波形へ進めます。既存の波形データ・ズーム・シークを共有し、歌詞マーカーは詳細表示の上段で編集します。

「秒数で指定」では開始・終了ハンドル、秒数入力、現在位置を設定するボタン、±0.1秒を利用できます。ハンドルの左右キーは0.01秒、Shift併用は0.1秒、Home/Endは移動可能な端まで動かします。音源末尾は小数を丸めず実尺まで選べます。数値欄は0.01秒刻みで調整できます。

範囲外を暗くし、選択部分と両端をアクセント色で示します。ハンドルは上下の位置を分け、短い区間でも2つの操作対象が重ならないようにしました。広い画面では波形と数値操作を左右に、狭い画面では上下に並べます。操作対象は44px以上です。区間と長さはカードとMP4ボタン付近に表示します。

## 再生

通常の再生と波形クリックは、指定区間の外を含む曲全体の操作です。通常再生中の「現在位置を開始に／終了に」は再生を継続します。

「選択範囲を試聴」は開始位置から終了位置までを再生します。Web Audioのバッファ開始オフセットと長さを指定し、画面のanimation frameが停止しても範囲外の音が流れ続けないようにしています。「範囲を繰り返す」は初期OFFで、ON時にはWeb AudioのloopStart/loopEndを使います。通常再生のループとは独立しています。繰り返しをOFFにすると、現在の周回の残りを再生して終了します。

ドラッグでは再生を止めます。範囲試聴中の境界編集でも停止し、編集後に自動再生しません。生成済みの範囲試聴では、選択クリップと同じ時間軸で映像・曲名表示を確認できます。通常再生の曲名表示は曲全体の時間軸です。

## 保存と出力の契約

`exportSettings.range` は `full | custom | socialHook | highlight`。任意の `customRange: {start, end}` は元曲の秒数です。DB format 3、project schema 2は変更しません。

有効な指定は、保存・復元・Undo／Redo・別タブの競合分岐・プロジェクトJSONへ引き継ぎます。入力途中の空欄や不正な文字は一時的なUI下書きで、直前の有効値を上書き保存しません。下書きが不正な間は試聴・出力を無効にし、再読込では保存済みの有効値を復元します。

MV再生成、配色・曲名・画面比等の変更では指定を保持します。曲全体・SNS推奨へ切り替えても手動指定値は保持します。別の音源への正常な差し替えで曲全体へ戻し、古い指定を削除します。同じ音源の復元・再接続や読込失敗では指定を残します。

UIと各出力バックエンドは共通の検証処理を使います。非数値、逆転、音源外、1フレーム未満の区間は理由を表示して拒否します。不正なcustom指定や選べないSNS区間を、曲全体の書き出しへ置き換えません。時刻付きLRCの判定を本家形式にも適用し、縦型ショートではプレビュー・出力・画面比表示を9:16へ揃えます。手動の画面比は残し、手動指定へ戻したときに復元します。fps変更時にも最短区間を再検証します。

書き出し開始時に範囲をコピー・固定し、元曲の開始秒から映像と音声を切り出します。ファイル時刻は0秒開始です。映像フレーム数は区間長×fpsを丸めるため、区間長と映像尺には最大1フレーム程度の差があります。曲名の冒頭・末尾表示も選択クリップの範囲を使います。区間変更で古い出力検査結果・共有ファイルを無効化します。書き出し中は編集操作をロックしますが、処理パネルの中止操作は維持します。

## 検証

`dev/export_range_test.cjs` は範囲境界、最短フレーム、音源／映像上限、無効値、出力スナップショットを検証します。`dev/export_range_e2e.cjs` は実UIと合成素材を使い、次を確認します。

- MV生成前の音源試聴、通常再生中の境界指定、数値・キーボード・ドラッグ・タッチ、ズーム、小数の曲末尾。
- Web Audioのオフセット・長さ・ループ境界、animation frame停止中の終了、繰り返しの解除。
- 不正入力とfps変更時の出力制御、保存・復元・履歴・JSON・別タブ分岐、音源の読込失敗・再接続・正常な差し替え、SNS範囲との切替。
- 375／768／1024／1100／1440pxの通常・試聴中・エラー表示、操作対象のサイズ。
- 音声周波数が区間ごとに220／440／880Hzとなる素材の実MP4。FFmpegでデコードし、選択した音声部分と区間途中の周波数切替位置を独立に確認。
- 出力の先頭映像を、元曲の選択開始秒で描いた画像と比較。FFprobeでH.264／AAC、尺を検査し、FFmpegで全体デコード。
- 編集ロック下の中止・範囲保持・再試行と、AAC代替処理後の音声区間。

2026-10-26の最終ビルドで、単体6群・ブラウザー90群／ケース（範囲指定21群を含む）が成功しました。

今回の実行結果は [検証サマリー](qa/export-range-2.5.0/summary.json) と [範囲E2E](qa/export-range-2.5.0/range.json) に記録しています。既存のUX・保存・可読性・曲名・動画検証も同じビルドで実行します。再実行手順は [VALIDATION](VALIDATION.md) を参照してください。

Linux Chromiumで検証します。物理端末・実際のOS保存ダイアログを検証したという意味ではありません。通常の再生と切り出し試聴の操作、最終MP4の音声と映像をそれぞれ確認してください。
