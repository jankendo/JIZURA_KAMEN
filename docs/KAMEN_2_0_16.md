# KAMEN 2.0.16

生成映像の前景・反復・意味の動きを変更し、判定を厳格化する。

- 元画像を160px幅・最大240px高で解析。RGBの連結領域を輪郭・コントラストで選び、最大4領域を実際のアルファマスクにする。領域を除いた背景は隣接画素で補間し、原画の切り抜きを独立した座標・倍率で描画する。処理結果と色処理を画像単位でキャッシュする。
- 奥行きは領域の縦位置によるヒューリスティック。人物・旗・拳の認識や学習済み深度ではない。均一画像など有効領域がない場合は原画描画へ戻り、前景認識成功を偽装しない。補間境界に継ぎ目が出る可能性はQAにも記載する。
- 集合は収束、誇り・輝きは光の掃引、荒れ狂いは決定的な不規則振動、声は奥からの到着、ここにいるは固定する。歌詞本文と表示開始は保持する。手動指定区間に自動処理を重ねない。
- 反復の4段階は文字幅、装飾の重ね数、装飾速度、背景コントラストを増加させる。主歌詞は常に全文を1つの正規レイヤーとして表示。薄い装飾文字は歌詞監査の正規マスクに含めない。
- クライマックスのポスター処理を保持し、37→40→43→46秒相当の反復で重なり、斜線、前景移動、コントラストを追加する。最後の開幕フレームへのループ処理は保持する。
- 前景実現検査は同じ時刻・カメラ・色で前景だけを止めた比較映像との差を測る。これは実画素の動作可視性であり、意味の理解や観客評価ではない。画像前景の新規性は固定カメラ・固定色のアルファマスクの連続差を測定。従来の歌詞前景の値は別診断として残す。係数は従来の260を流用し、高得点を作るための緩和はしない。
- 正規歌詞ラスタの12×8占有率の変化を検査し、8秒を超える停滞を独立ゲートにする。画像のクロップはこの検査に含まれない。
- 新規性・前景新規性・静動差・意味の実現のいずれかが80未満または未計測なら総合は最大89。意味・動作・指定した拍の実現が未計測なら100点認定禁止。画素Impactは観客評価ではないとUIに明記する。芸術的100点の達成は主張しない。

新しい生成処理は素材からの再生成で適用される。既存MP4を自動で置き換えない。
