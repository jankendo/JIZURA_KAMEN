# KAMEN 2.0.17

## 生成側の変更

同じ画像のクロップだけではなく、独立してフレーミングした二面・三面・四面、余白、上方向への構図、停止した全景、地域マスクによる前景の合流を使う。通常歌詞は集合／戦士／誇り／荒れ狂い／声／固定の意味で構図を選ぶ。フォントの統一感と原文全文は保持する。

ラララ・オオオの四回反復は、単独→二面→四面スタンド→全景へ合流する。画像前景の数も1→2→3→4と増え、文字の幅・密度・大きさを段階的に変える。最終段階が最大文字。マスクはRGB連結領域であり、人物・旗・群衆の物体認識や推定深度を主張しない。

ASSET PACKのストーリーボードには、マクロ章だけでなく、実際の各歌詞ショットとその構成を出力する。手動指定区間は保持する。自動修復・SNS再編集でもこの構成を維持する。

## ループ

最後の0.4〜0.65秒では背景だけを冒頭に戻す。最後の歌詞は境界まで保持し、タイトルは次の再生の冒頭で表示する。歌詞とタイトルをクロスフェードしない。短い範囲の書き出しと、音声長で切った範囲でも、その範囲の先頭背景へ戻す。

ループQAは実際の背景のRGB・輪郭・速度を比較し、全文字を含む画面差と意図的な文字の境界交換を別に報告する。全文字の一致をシームレスループと偽装しない。音声端点は従来の推定検査で、音声そのものは変更しない。

## 評価の依存関係

基準80未満または未計測の場合：

- Style Realization／Perceptual Novelty → Creative最大89
- Foreground Novelty → Visual World／Composition最大89
- Temporal Contrast → Motion最大89
- Lyric Foreground Novelty → Typography最大89

元の工学的な検査値は `engineeringScoresBeforeDependencies` に残し、演出の弱点を反映した点数と区別する。semanticDirection・motionRealization・impactBeatSyncが未計測なら100点認定禁止を維持。未計測を推定の成功として埋めない。芸術的な100点の達成は主張しない。

前景QAの正規マスクは、実際に描画される前景の配置と数を使い、カメラ・色・歌詞を除いて比較する。変化係数や判定閾値は緩めない。
